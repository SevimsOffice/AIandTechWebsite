Hack 1

Longer Turns By Default

Hard tasks run longer on Fable 5 than on previous models by default. That is great when the work is genuinely complex, but on an ambiguous task it can over-plan and survey options instead of just acting. To keep it moving, add this:

Prompt · Stop Over-Planning

When you have enough information to act, act. Do not re-derive facts already established in the conversation, re-litigate a decision the user has already made, or narrate options you will not pursue in user-facing messages. If you are weighing a choice, give a recommendation, not an exhaustive survey. This does not apply to thinking blocks.

Hack 2

State The Boundaries

Fable 5 can occasionally take actions you did not ask for, like drafting an email when you were only thinking out loud. Define what it should and should not do so it reports back instead of running off:

Prompt · Set The Boundaries

When the user is describing a problem, asking a question, or thinking out loud rather than requesting a change, the deliverable is your assessment. Report your findings and stop. Don't apply a fix until they ask for one. Before running a command that changes system state (restarts, deletes, config edits), check that the evidence actually supports that specific action. A signal that pattern-matches to a known failure may have a different cause.

Hack 3

Parallel Subagents

Fable 5 spins up parallel subagents more readily than prior models. Lean into it, but tell it when delegation is actually appropriate so it does not fan out on tiny tasks:

Prompt · Guide Delegation

Delegate independent subtasks to subagents and keep working while they run. Intervene if a subagent goes off track or is missing relevant context.

MAKE THEM STICK

Save these three where Fable can see them (your project instructions or a memory file) and they keep working every session. That is the whole game: the model got smarter, so your job shifts from typing perfect questions to setting clear rules.
